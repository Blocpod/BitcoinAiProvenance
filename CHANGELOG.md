# Changelog

All notable changes are documented here. This project follows semantic versioning once the protocol reaches a stable public release.

## [0.1.0] - 2026-08-11

### Added

- Domain-separated Ed25519 signed envelopes
- Canonical JSON validation
- Content-addressed artifact storage
- Provenance receipts and lineage verification
- Agent session policies and replay protection
- Merkle batches and inclusion proofs
- Bitcoin Core RPC anchoring and confirmation verification
- Dependency-free CLI and local explorer
- Autonomous research program and release gauntlet
- Security, threat-model, RFC, architecture, and roadmap documentation
